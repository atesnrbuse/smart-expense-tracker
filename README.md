# Akıllı Harcama Takipçisi

Kullanıcının belirlediği gün sayısı boyunca yaptığı günlük harcamaları toplayan, ortalama harcama tutarını hesaplayan ve girilen toplam bütçeye göre bütçe aşım durumunu analiz eden Python uygulaması.

---

## Özellikler

- **Dinamik Veri Girişi:** İstenilen gün sayısı kadar ondalıklı harcama tutarı girişi.
- **Finansal Hesaplamalar:** 
  - Toplam yapılan harcama tutarı,
  - Günlük ortalama harcama tutarı.
- **Bütçe Kontrolü:** Toplam harcamanın belirlenen bütçeyi aşıp aşmadığını denetleyen karar mekanizması.
- **Modüler Yapı:** Sürecin tek bir fonksiyon altında toplanması.

---

## Kullanılan Teknolojiler

- **Dil:** Python
- **Kullanılan Yapılar:**
  - Fonksiyonlar (`def`)
  - Döngüler (`for`, `range`)
  - Karar Yapıları (`if-else`)
  - Veri Tipleri & Yapıları (`float`, `list`, `sum()`)
  - Standart Konsol Girdi/Çıktı Fonksiyonları
